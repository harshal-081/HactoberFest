# Test Data Directory

Place your actual student solution test image here:

`dfa-solution.png` (or `.jpg`, `.jpeg`, `.webp`)

### Example Test Case
* **Problem**: "Design a DFA over {0,1} that accepts strings containing an even number of 1s."
* **Image**: A photo or diagram of a drawn DFA (correct, incorrect, or handwritten).

You can also specify a custom image location by setting the `TEST_IMAGE_PATH` environment variable:
```powershell
$env:TEST_IMAGE_PATH="C:\path\to\your\solution.png"
npm run test:review
```
